## Ch02 · Variables and Input

Programs work with values: numbers, letters, and text. A variable gives a value a name, so the program can use it and change it. This chapter covers the types C provides, how arithmetic works on them, how text is stored in C, and how a program reads what the user types.

The steps are:

* [Variables](#goto/01-variables): declaring variables, the basic types, and constants.
* [Arithmetic](#goto/02-arithmetic): the operators, integer division, and converting between types.
* [Strings](#goto/03-strings): text as arrays of characters, and the functions that work on them.
* [User input](#goto/04-user-input): reading a line and a number from the keyboard.
* [Command-line arguments](#goto/05-command-line-arguments): receiving values when the program starts.
* [Summary](#goto/06-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
