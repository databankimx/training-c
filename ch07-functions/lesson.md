## Ch07 · Functions

Up to now, every program has been one `main` function. This chapter splits a program into named functions, so each piece has a job, and the same job can be used from several places. You'll learn how to define and declare a function, how values go in through parameters and come out through return values, how arrays are passed, how a function can change its caller's variables through pointers, and how a function can call itself.

The steps are:

* [Defining functions](#goto/01-defining-functions): defining and calling a function, and declaring it before use.
* [Parameters](#goto/02-parameters): passing arguments by value, and why a copy is made.
* [Return values](#goto/03-return-values): sending a result back, and giving each function its own name.
* [Arrays as parameters](#goto/04-arrays-as-parameters): passing an array, and why its size has to be passed too.
* [Pointer parameters](#goto/05-pointer-parameters): letting a function change its caller's variables.
* [Recursion](#goto/06-recursion): a function that calls itself, and the rules that stop it.
* [Summary](#goto/07-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.

---

*This chapter is written for this course. Functions are described in the C17 standard. C has no default arguments or function overloading, so those C++ topics are not covered here.*
